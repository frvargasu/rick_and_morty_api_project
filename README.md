
# Rick y Morty API Project

Este proyecto fue creado con Vite y React para consumir la API pública de Rick y Morty.

## Scripts principales
- `npm run dev`: Inicia el servidor de desarrollo
- `npm run build`: Compila la aplicación para producción
- `npm run preview`: Previsualiza la app compilada

## Personalización
Puedes modificar los componentes en la carpeta `src` para mostrar personajes, episodios y más información de la API.
